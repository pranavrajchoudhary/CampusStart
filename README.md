## 📌 Project Overview

**CampusStart** is a **full-stack campus management and student support platform** built using the **MERN stack**, enhanced with **Python-based Machine Learning modules** for data analysis and intelligent decision support.

The project combines:
- 🌐 **Modern web development (MERN)**
- 🧠 **Practical Machine Learning using Python**
- 📊 **Data-driven features for campus use cases**

This project is developed incrementally with clear separation between **frontend**, **backend**, and **ML components**.
 

## 🧩 Tech Stack

### 🌐 MERN Stack (Core Application)
- **MongoDB** – Database
- **Express.js** – Backend framework
- **React.js** – Frontend UI
- **Node.js** – Server runtime

### 🧠 Machine Learning & Data
- **Python**
- **NumPy**
- **Pandas**
- **Matplotlib / Seaborn**
- **Scikit-learn**
